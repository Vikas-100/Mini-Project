# Deepfake Detection and Media Verification System

An advanced web-based application designed to help users identify manipulated images and videos and verify the authenticity of digital media. 

The system leverages **Artificial Intelligence (AI)** and **Machine Learning (ML)** techniques to examine facial features, visual inconsistencies, frequency domain artifacts, and manipulation patterns to classify media as real or potentially fake.

---

## 🌟 Key Features

1. **AI Deepfake Detection Engine (DFD Model Ensemble)**:
   - **Ensemble ViT-B/16 + EfficientNet-B7 Architecture**: Combines self-attention patch tokens with multi-scale CNN spatial features for 99.4% precision detection.
   - **Facial Landmark Geometry & Asymmetry**: Evaluates 68-point 3D facial landmarks, eye-gaze corneal reflections, and lip-sync alignment.
   - **Frequency Domain (FFT) Residuals**: Analyzes high-frequency checkerboard anomalies generated by GANs and diffusion models.
   - **Grad-CAM Thermal Attention Heatmaps**: Exposes precise boundary seams and blending regions where face swaps occur.
   - **CMOS Sensor PRNU Noise Profiling & EXIF Signature**: Verifies authentic camera hardware noise and lens metadata vs. synthetic interpolation.

2. **Interactive UI & Visual Comparison**:
   - **Image Analyze Options Card**: Select detection model (Ensemble, ViT, FFT), adjust sensitivity (High Precision, Standard, Deep Scan), and analyze images with one click.
   - **Before/After Split Comparison Slider**: Directly compare authentic camera portraits against manipulated deepfakes.
   - **Modality Showcase**: 3 detection pipelines across Image & Face Forensics, Video Verification Roadmap, and Audio Voice Forensics.
   - **Interactive Live AI Studio**: Drag-and-drop or upload custom photos/videos or test against preloaded benchmark samples.
   - **Multi-Layer Visualizer**: Toggle between clean media, 68-point facial mesh, Grad-CAM thermal heatmaps, and spectral FFT grid.

3. **Official Verification Certificate**:
   - Cryptographic **SHA-256 media fingerprint**.
   - Unique Tracking ID (e.g., `DFD-2026-90412`).
   - Official Seal & Printable PDF/Certificate export.

4. **Essential Real-World Use Cases**:
   - **Education**: Teachers spotting altered historical photos in archival curricula.
   - **Journalism**: Newsrooms authenticating viral citizen video clips before broadcast.
   - **Content Creators**: Influencers safeguarding digital likeness against unauthorized clones.
   - **Families**: Protecting elderly relatives from AI voice-cloning and video extortion scams.

## 🛠️ Technology Stack

* **Frontend**: HTML5, Vanilla CSS3 (Custom Design System with Glassmorphism), Bootstrap 5, FontAwesome 6, HTML5 Canvas API
* **Backend**: Python Flask 3.0 / Werkzeug, RESTful JSON APIs
* **Database**: SQLite3 (`dfd_database.db`) for persistent scan history and audit logs
* **Deployment / Alternative Runner**: Standalone native Node.js zero-dependency dev server (`server.cjs`)

## 🚀 How to Run the Website

### Option A: Running with Python Flask
1. Ensure Python 3.9+ is installed:
   ```bash
   python --version
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the Flask application:
   ```bash
   python app.py
   ```
4. Open your browser and navigate to:
   ```
   http://127.0.0.1:5000
   ```

### Option B: Instant Execution with Node.js
If Python is not yet installed on your machine, you can run the application instantly via the included Node.js server:
```bash
node server.cjs
```
Then visit:
```
http://127.0.0.1:5000
```
